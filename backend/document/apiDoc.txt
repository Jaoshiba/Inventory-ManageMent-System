
Base URL= `/api`

---

## 1. [POST] /products (เพิ่มสินค้าใหม่)
เอาไว้ใช้แอดสินค้าใหม่เข้าระบบ โดยรหัสสินค้า (SKU) ห้ามซ้ำกับของที่มีอยู่แล้ว

* **URL:** `/products`
* **Method:** `POST`
* **Header:** `Content-Type: application/json`

### ข้อมูลที่ต้องส่งไป (Body)
| ชื่อฟิลด์ | ชนิดข้อมูล | เป็นค่าว่าง/ไม่ส่ง | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `name` | string | ใช่ | ชื่อสินค้า |
| `sku` | number | ใช่ | รหัสสินค้า (ห้ามซ้ำ) |
| `cost` | number | ใช่ | ต้นทุนสินค้า |
| `price` | number | ใช่ | ราคาที่จะขาย |
| `stockRemain` | number | ไม่จำเป็น | สต็อกเริ่มต้น (ถ้าไม่ส่งมา จะเป็น default 0) |
| `categoryId` | number | ใช่ | ไอดีของหมวดหมู่สินค้า |

**exsample payload:**
```json
{
  "name": "คีย์บอร์ดไร้สาย",
  "sku": 100201,
  "cost": 1200.00,
  "price": 1890.00,
  "stockRemain": 50,
  "categoryId": 3
}
```

### exsample response 

* **ถ้าผ่าน (201 Created):** จะได้ข้อมูลสินค้าทั้งหมดรวมถึง ID ที่สร้างใหม่กลับมา
  ```json
  {
    "id": 15,
    "sku": 100201,
    "name": "คีย์บอร์ดไร้สาย",
    "cost": 1200.00,
    "price": 1890.00,
    "stockRemain": 50,
    "categoryId": 3
  }
  ```

* **ถ้าไม่ผ่าน (400 หรือ 409):** เช่น ส่งข้อมูลผิด หรือ SKU ซ้ำกับของเดิมในระบบ
  ```json
  {
    "error": "Product with this SKU already exists."
  }
  ```

* **ระบบพัง (500 Error):**
  ```json
  {
    "error": "Internal server error"
  }
  ```

## 2. [GET] /products/low-stock (เช็กสินค้าสต็อกใกล้หมด)
เอาไว้ดึงรายการสินค้าที่สต็อกเหลือน้อยกว่าเกณฑ์มาดู ถ้าเราไม่ส่งยอดสต็อกมา ระบบจะตั้งค่าเริ่มต้นไว้ที่ต่ำกว่า 5 ชิ้นให้อัตโนมัติครับ

* **URL:** `/products/low-stock`
* **Method:** `GET`
* **Query Parameter:** `amount` (ไม่จำเป็นต้องใส่) 
  * เช่น อยากดูชิ้นที่เหลือน้อยกว่า 10 ชิ้น ก็เรียกไปที่: `/api/products/low-stock?amount=10`

### ผลลัพธ์ที่จะได้กลับมา

* **ถ้าสำเร็จ (200 OK):** จะได้เป็น List รายการสินค้าที่สต็อกเหลือน้อยกลับมา
  ```json
  [
    {
      "id": 4,
      "sku": 100105,
      "name": "สายชาร์จ Type-C",
      "cost": 80.00,
      "price": 150.00,
      "stockRemain": 2,
      "categoryId": 1
    },
    {
      "id": 8,
      "sku": 100109,
      "name": "เมาส์ไร้สาย",
      "cost": 350.00,
      "price": 590.00,
      "stockRemain": 4,
      "categoryId": 1
    }
  ]
  ```

* **ถ้ามีปัญหา (500 Error):**
  ```json
  {
    "error": "Internal server error"
  }
  ```

## 3. [PATCH] /stock/adjust (ปรับยอดสต็อก)
เอาไว้แก้จำนวนสินค้าคงเหลือในคลัง โดยอ้างอิงจาก SKU

* **URL:** `/stock/adjust`
* **Method:** `PATCH`
* **Header:** `Content-Type: application/json`

### ข้อมูลที่ต้องส่งไป (Body)
| ชื่อฟิลด์ | ชนิดข้อมูล | จำเป็นไหม | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `sku` | number | ใช่ | รหัสสินค้าที่ต้องการปรับสต็อก |
| `amount` | number | ใช่ | จำนวนที่จะปรับ (เช่น ใส่ `10` เพื่อเพิ่มสินค้า หรือใส่ `-5` เพื่อลดสินค้า) |
| `note` | string | ไม่จำเป็น | บันทึกช่วยจำเพิ่มเติม (เช่น เติมของ หรือ ของชำรุด) |

** exsample payload:**
```json
{
  "sku": 100201,
  "amount": 10,
  "note": "รับสินค้าเข้าเพิ่มเติมจาก Vendor"
}
```

### exsample response

* **ถ้าสำเร็จ (200 OK):** จะได้ข้อมูลสินค้าที่อัปเดตสต็อกล่าสุดแล้วกลับมา
  ```json
  {
    "id": 15,
    "sku": 100201,
    "name": "คีย์บอร์ดไร้สาย",
    "cost": 1200.00,
    "price": 1890.00,
    "stockRemain": 60,
    "categoryId": 3
  }
  ```

* **ถ้ามีปัญหา (400 หรือ 404):** เช่น หา SKU ไม่เจอ หรือกรอกจำนวนผิดพลาดตามเงื่อนไข validation
  ```json
  {
    "error": "Product with SKU 100201 not found."
  }
  ```

* **ระบบเอ๋อ (500 Error):**
  ```json
  {
    "error": "Internal server error"
  }
  ```
