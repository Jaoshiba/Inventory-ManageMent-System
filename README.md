# Inventory Management System (StockFlow)

ระบบบริหารจัดการและอัปเดตสต็อกคลังสินค้า (StockFlow) ออกแบบและพัฒนาขึ้นเพื่อจัดการจำนวนสินค้า ตรวจสอบระดับสต็อกสินค้าคงเหลือต่ำกว่าเกณฑ์ความปลอดภัย และการทำบันทึกปรับปรุงจำนวนสต็อก (Stock Adjust) อย่างเป็นระบบและเป็นมิตรต่อผู้ใช้งาน

*หมายเหตุ: ส่วนติดต่อผู้ใช้งาน (UI) ของระบบนี้ ได้รับการออกแบบและถอดแบบเลย์เอาต์มาจากโครงสร้างที่กำหนดในระบบดีไซน์อย่างละเอียด เพื่อให้ตอบโจทย์ด้าน UX/UI สูงสุด*

---

## 🛠️ Tech Stack (เทคโนโลยีที่ใช้)

### Frontend (หน้าบ้าน)
* **Framework:** Next.js 15 (React 19) - App Router
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Icons:** Lucide React

### Backend (หลังบ้าน)
* **Runtime/Framework:** Node.js / Next.js API Routes (หรือระบุเทคโนโลยีหลังบ้านจริงของคุณ เช่น Express / NestJS)
* **Database & ORM:** PostgreSQL / TypeORM (หรือระบุประเภทฐานข้อมูลของคุณ)

## 📂 Project Structure (โครงสร้างโปรเจกต์)

ระบบได้รับการแยกโฟลเดอร์ฝั่งผู้ใช้ (Frontend) และบริการจัดการส่วนข้อมูล (Backend) ออกจากกันอย่างเป็นระบบที่ระดับ Root Directory:

```text
Inventory-Management-System/
├── backend/          # ซอร์สโค้ดฝั่งเซิร์ฟเวอร์หลังบ้านและฐานข้อมูล
└── frontend/         # ซอร์สโค้ด Next.js ฝั่งผู้ใช้งานหน้าบ้าน
```

## 🚀 Getting Started (วิธีการรันโปรเจกต์ภายในเครื่อง)

กรุณาทำตามขั้นตอนต่อไปนี้เพื่อทำการรันโปรเจกต์จำลองภายในเครื่องของคุณ:

### 1. การเปิดใช้งานระบบหลังบ้าน (Backend Setup)
1. เปิด Terminal แล้วเข้าไปที่โฟลเดอร์หลังบ้าน:
   ```bash
   cd backend
   ```
2. ทำการติดตั้ง Packages ที่จำเป็น:
   ```bash
   npm install
   ```
3. กำหนดค่าสภาพแวดล้อม (Environment Variables) เช่น พอร์ตของหลังบ้าน และการเชื่อมต่อฐานข้อมูล โดยการสร้างไฟล์ `.env` (ดูตัวอย่างจาก `.env.example`)
4. สั่งเริ่มการทำงานระบบหลังบ้าน:
   ```bash
   npm run dev
   ```
   *ระบบหลังบ้านจะทำงานที่พอร์ตโดยทั่วไปคือ `http://localhost:3000` (หรือพอร์ตอื่น ๆ ตามที่คุณกำหนด)*

---

### 2. การเปิดใช้งานระบบหน้าบ้าน (Frontend Setup)
1. เปิด Terminal อีกหนึ่งตัวแล้วเข้าไปที่โฟลเดอร์หน้าบ้าน:
   ```bash
   cd frontend
   ```
2. ทำการติดตั้ง Packages:
   ```bash
   npm install
   ```
3. ตั้งค่าการเชื่อมโยงระบบพอร์ตหลังบ้านในไฟล์ `next.config.ts` (หรือ `next.config.js`) ในส่วนของ `rewrites` ให้ตรงกับพอร์ตหลังบ้านจริงของคุณ
4. สั่งเริ่มทำงานระบบหน้าบ้าน:
   ```bash
   npm run dev
   ```
5. เปิดเข้าชมผ่านเว็บเบราว์เซอร์ที่ลิงก์: [http://localhost:3001](http://localhost:3001)

## 🔌 API Endpoints ที่ระบบเรียกใช้งาน

ระบบฝั่งหน้าบ้านมีการเชื่อมต่อแบบครบครันตามสัญญารับส่งข้อมูลผ่าน Endpoints ต่อไปนี้:

| Method | Endpoint | Description |
| :---: | :--- | :--- |
| **POST** | `/api/products` | ลงทะเบียนและสร้างสินค้าชิ้นใหม่เข้าระบบ |
| **GET** | `/api/products/low-stock` | คิวรีดึงรายการสินค้าทั้งหมดที่สต็อกต่ำกว่าเกณฑ์ความปลอดภัย |
| **PATCH** | `/api/stock/adjust` | ปรับปรุงตัวเลขจำนวนคลังสินค้าคงเหลือ (Stock Adjust) อ้างอิงตาม SKU |

## ✨ Key Features (ฟีเจอร์เด่นของระบบ)
* **Real-time Low Stock Dashboard:** คอยเฝ้าระวังและคิวรีสินค้าที่มีระดับสต็อกต่ำกว่าเกณฑ์ความปลอดภัยเพื่อแจ้งเตือนเจ้าหน้าที่คลังสินค้าในทันที
* **Interactive Quick Stock Adjust:** ผู้ใช้สามารถคลิกเลือกสินค้าบนตารางเพื่อนำข้อมูลมาแสดงที่แผงควบคุมด้านขวา และใช้ปุ่มลัด (+10, -5, +50) เพื่อลดข้อผิดพลาดและเพิ่มความรวดเร็วในการป้อนข้อมูล
* **Responsive Layout:** เลย์เอาต์หน้าต่างแยกสัดส่วนการแสดงข้อมูลและการโต้ตอบอย่างเป็นมิตร ทำงานได้ลื่นไหลโดยไม่ต้องสลับหน้าจอ (No-refresh interaction)
